# PERN Stack Costume Management Application

A full-stack, 3-tier web application designed to manage, browse, and track costume inventories. Built with a modern PERN stack (PostgreSQL, Express, React, Node.js) with decoupled deployment pipelines.

## 🚀 Live Demo & Links

- **Frontend Application:** [jennythepirate.com](https://www.jennythepirate.com)

>**Note on Live Demo:** Hosted on Render's free tier. Please allow up to 45 seconds for the initial load while the server wakes up!

---

## 🛠️ Architecture & Tech Stack

- **Frontend:** React (Vite) — Deployed on **Netlify**
- **Backend:** Node.js & Express REST API — Deployed on **Render**
- **Database:** PostgreSQL — Hosted on **Neon**

---

## Features

- **Data-Driven Frontend:** Clean React interface that dynamically fetches, structures, and renders costume inventory data from the Express backend.
- **Optimized SQL Queries:** Efficient database access patterns built natively for PostgreSQL.
- **Environment Isolation:** Secure configuration separating production endpoints from local development.
- **CORS & SSL Protected:** Secure API communication between the Netlify client and Render server.
